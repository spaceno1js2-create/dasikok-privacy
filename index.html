1. 손쉬운 사용(Accessibility) 권한 사용 목적

다시콕은 YouTube 홈 피드에서 이미 본 추천 영상을 추천 피드 새로고침 이후에도 다시 확인할 수 있게 하기 위해 손쉬운 사용(AccessibilityService) 권한을 사용해요. 이 권한은 YouTube 앱(com.google.android.youtube)의 홈 추천 피드 화면에서만 동작하도록 범위가 제한되어 있고, 다른 앱의 화면은 전혀 읽지 않아요.

2. 읽는 정보

YouTube 홈 추천 피드 화면에 이미 표시된 추천 영상의 제목·채널명·길이·조회수·게시 시점만 읽어요. 화면을 녹화하거나 캡처하지 않고, 비밀번호·메시지·검색어 같은 무관한 입력은 전혀 수집하지 않아요. 손쉬운 사용 권한이 전달하는 원문 화면 구조(accessibility tree)는 위 정보를 추출하는 동안만 메모리에 존재하고, 추출 후 즉시 버려져요 — 원문 자체는 저장하지 않아요.

3. 저장 위치

위 추천 기록은 이 기기에만 저장돼요(로컬 저장, Room 데이터베이스). 다시콕 자체 코드는 이 기록을 서버나 다른 백엔드로 전송하지 않아요 — 다시콕 코드에는 이런 네트워크 통신 기능이 아예 없어요. 기기 자동 백업에도 포함되지 않도록 설정돼 있어요.

4. 삭제

설정 화면의 "전체 기록 삭제"를 누르면 저장된 추천 기록을 즉시 모두 지울 수 있어요. 앱을 삭제하면 기기에 저장된 모든 기록도 함께 사라져요. 오래된 기록은 저장 공간을 제한하기 위해 자동으로도 정리돼요.

5. Google Mobile Ads SDK (광고)

저장된 추천 기록을 확인하려면 짧은 보상형 광고를 한 개 시청해야 해요. 이 광고는 Google Mobile Ads SDK(Google AdMob)로 제공되며, 현재 배포 버전은 실제(운영) AdMob 광고 단위를 사용해 실제 광고를 표시해요.

다시콕이 접근성 서비스로 읽어 이 기기에 저장한 추천 기록(위 1~4번)은 광고 SDK에 전달되지 않으며, 광고 타게팅이나 사용자 프로파일링에 사용되지 않아요. 다만 이 SDK는 광고를 요청·표시하기 위해 Google과 직접 통신하며, 다시콕과는 별개로 아래 정보를 자체적으로 처리할 수 있어요:

  • IP 주소(기기의 대략적인 위치 추정용)
  • 광고 관련 상호작용(광고 표시, 탭 등)
  • 진단 정보(앱 실행 시간 등 SDK/광고 성능 지표)
  • 기기·계정 식별자(광고 ID 등 — 기기의 "설정 > 개인정보 보호"에서 재설정하거나 삭제할 수 있어요)

이 정보는 전송 중 암호화(TLS)돼요. Google은 이 정보를 광고 제공, 광고 성과 분석, 부정 사용 방지, SDK 성능 관리 등을 위해 Google의 개인정보처리방침과 AdMob 정책에 따라 사용할 수 있어요.

6. 제3자 서비스 제공자

광고 표시를 위해 Google Mobile Ads SDK(Google LLC)를 사용해요. 이 외에 다시콕이 직접 연동하는 제3자 서비스는 없어요 — 별도 분석(analytics)·크래시 리포팅 SDK도 사용하지 않아요.

7. 데이터 보존 및 삭제

다시콕 추천 기록: 위 4번(삭제) 참고 — 사용자가 직접 삭제하거나, 저장 공간 제한에 따라 자동으로 정리돼요. 광고 SDK가 처리하는 정보: Google이 자체 정책에 따라 보유·삭제하며, 다시콕은 이 정보를 직접 보관하지 않아요.
