1. Purpose of the Accessibility permission

DasiKoK uses the Accessibility permission (AccessibilityService) so that recommendation videos you've already seen on YouTube's home feed can still be found after the feed refreshes and they disappear. This permission is scoped to work only on the YouTube app's (com.google.android.youtube) home recommendation feed screen — it never reads the screen content of any other app.

2. Information read

DasiKoK reads only the title, channel name, duration, view count, and publish time of recommendation videos that are already displayed on the YouTube home recommendation feed screen. It does not record or capture the screen, and it never collects unrelated input such as passwords, messages, or search queries. The raw screen structure (accessibility tree) delivered by the Accessibility permission exists in memory only while this information is being extracted, and is discarded immediately afterward — the raw structure itself is never stored.

3. Where data is stored

The recommendation history above is stored only on this device (local storage, a Room database). DasiKoK's own code never transmits this history to a server or any other backend — there is no networking functionality in DasiKoK's own code for this purpose. It is also configured to be excluded from the device's automatic backup.

4. Deletion

Tapping "Delete all history" in Settings immediately deletes all stored recommendation history. Uninstalling the app deletes all history stored on the device as well. Older history is also cleared automatically to keep storage bounded.

5. Google Mobile Ads SDK (advertising)

Viewing a saved recommendation history requires watching one short rewarded ad. This ad is served by the Google Mobile Ads SDK. Unlike DasiKoK's own recommendation history (sections 1–4 above), this SDK communicates directly with Google to display ads and may process the following on its own:

  • IP address (used to estimate the device's approximate location)
  • Ad-related interactions (ad impressions, taps, etc.)
  • Diagnostic information (app runtime and other SDK/ad performance metrics)
  • Device and account identifiers (such as the advertising ID — you can reset or delete this from your device's "Settings > Privacy")

This information is encrypted in transit (TLS). DasiKoK currently uses only Google's official test ads — a production ad unit has not yet been connected.

6. Third-party service providers

DasiKoK uses the Google Mobile Ads SDK (Google LLC) to display ads. It does not integrate with any other third-party service directly — no separate analytics or crash-reporting SDK is used.

7. Data retention and deletion

DasiKoK's own recommendation history: see section 4 (Deletion) above — deleted by the user directly, or cleared automatically once storage limits are reached. Information processed by the ad SDK: Google retains and deletes this according to its own policies; DasiKoK does not directly store this information itself.
